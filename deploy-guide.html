🆕 第一次開店
0

產生你的店家網站包

  1. 打開開店產生器（下方按鈕）
  2. 填入店名、電話、地址、營業時間
  3. 填入 LINE 加好友、Facebook 粉絲團、Google 評論三個連結
  4. 填 GitHub 帳號名（還沒帳號沒關係，先填一個等下要註冊的名字）；Repo 名稱用預設 appleshop
  5. 「進階選項 → 真實數據」選一個模式（見下方說明）
  6. 按「產生」→ 下載 appleshop.zip → 解壓縮
zip 裡有一份 INSTALL.md，是這份教學的個人化版本，連你的網址都幫你填好了。
🚀 打開開店產生器
📡

「真實數據」要選哪個？

頁面最上面那排數字（LINE 好友、Google 評論、FB 追蹤數）要不要顯示，三選一。不確定就選第一個。

① 單純顯示推薦

不顯示那排粉絲數，只看客人點了幾次。什麼都不用設定，開箱即用，最輕鬆。

② 手動填數字

顯示你自己的 LINE / Google / FB 數字，自己填、隨時可改（照 INSTALL.md 開個網址就更新），系統還會自動幫你畫趨勢圖。零技術門檻。

③ API 自動串接進階

全自動抓最新數字，但需要自備 Cloudflare Worker 與各平台 API 金鑰，設定較複雜。zip 裡會附 REAL-DATA-API.md 教學。大多數店家用②就很夠了。

1

註冊 GitHub 帳號

已經有帳號可跳過這步。

  1. 前往 github.com/signup 註冊（約 1 分鐘）
  2. 帳號名要跟第 0 步填的「GitHub 帳號名」一致
2

建立一個新的 Repository

  1. 登入 GitHub → 右上角 ＋ → New repository
  2. Repository name 填 appleshop（跟第 0 步一致）
  3. 選 Public（免費版 Pages 需要 Public）
  4. 不要勾 "Add a README file"
  5. 按 Create repository
3

上傳網站檔案

  1. 在空 repo 頁面點 「uploading an existing file」
  2. 把解壓後的所有檔案整個拖進去（若有 .github/、scripts/ 子資料夾也一起拖）
  3. 下方按 Commit changes
💡 .github 資料夾開頭有「.」，Mac 預設是隱藏的。在 Finder 按 ⌘ + Shift + . 就能看到，記得一起拖進去。
4

開啟 GitHub Pages

  1. Repo 上方 Settings → 左側 Pages
  2. Source 選 Deploy from a branch
  3. Branch 選 main，資料夾選 / (root) → Save
  4. 等 30～60 秒，頁面上方會出現你的網址：
https://<你的帳號名>.github.io/appleshop/
5

測試（重要！）

  • 🌐 店家網站 = https://<帳號名>.github.io/appleshop/
  • 📊 後台儀表板 = 同網址加上 /stats.html
  • 📱 用手機掃 zip 裡的 qrcode-final.png
  • 點一下 LINE / Facebook / Google 按鈕
  • 再打開 stats.html，數字就會跳動 ✨
🔄 已經開過店，要更新

你已經有網站了，只是想把上面那排數字改成自己的（原本可能顯示到別人的），或換成新版。
你不用重新註冊、不用重建網站，只要換一個檔案就好。

1

重新產一份新檔

  1. 打開開店產生器（下方按鈕），填一次你的店家資料
  2. 「進階選項 → 真實數據」選你要的模式（①單純顯示 最輕鬆；②手動填數字 想顯示自己的粉絲數）
  3. 按「產生」→ 下載 zip → 解壓縮，裡面有一個 stats.html
🚀 打開開店產生器
2

去 GitHub 換掉舊的 stats.html

  1. 用電腦開 github.com 並登入
  2. 點進你當初放這個店網站的「倉庫（repository）」，名字裡通常有 appleshop 或你的店名
  3. 右上角點 Add file ▾ → Upload files
  4. 把剛下載的新 stats.html 拖進去（檔名要一樣叫 stats.html，才會蓋掉舊的）
  5. 往下捲，按綠色 Commit changes
  6. 等約 1 分鐘，網站就更新好了 ✅
💡 只需要換 stats.html 這一個檔，其他檔案都不用動。
3

確認 & 填數字（選了②的人）

  • 打開你的 stats.html，上面那排數字應該不再是別人的了
  • 若你選 ①單純顯示 → 那排粉絲數會消失，只剩點擊活動，完成！
  • 若你選 ②手動填數字 → 照 zip 裡的 INSTALL.md，開一個網址就能填入自己的 LINE / Google / FB 數字（之後隨時可改，還會自動畫趨勢圖）
常見問題
後台在哪？要另外登入嗎？

後台就是你網站的 stats.html 頁面，不用登入，打開網址就能看。

為什麼點了按鈕，數字沒有增加？

用「電腦」點不算數（防灌水設計）。請務必用手機掃 QR 後再點按鈕。

「真實數據」那排數字怎麼是空白 / 顯示「—」？

如果你選了 ②手動填數字，一開始是空的很正常，照 zip 裡的 INSTALL.md 開一個網址填入你的數字就會出現。如果你選 ①單純顯示，本來就不會有那排數字。

我的數字會跟別人混在一起嗎？

不會。每家店有獨立的資料空間，你只會看到自己店的數據，完全隔離。

網址打開是 404 或空白？

Pages 剛開啟需要等 1～2 分鐘；也請確認第 3 步的檔案有上傳成功（repo 裡要看得到 index.html）。
