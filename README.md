# 🍎 AppleShop Starter Kit

> 5 分鐘為你的店產生一個完整的數位行銷網站 — 落地頁 + DM + 統計儀表板 + 週報

**🌐 線上產生器:** https://magicbrian1206-maker.github.io/appleshop-starter/

## 這是什麼?
原本是燦坤華榮 AppleShop 自家的數位行銷系統,現在開源分享給其他 Apple 授權經銷店家使用。
填表 → 下載 zip → 5 分鐘部署到 GitHub Pages → 開店上線。

## 功能
- 📱 手機落地頁(QR 掃進來看到的頁面,3 個 CTA 按鈕)
- 🖼 A4 列印 DM
- 📊 Apple Watch 風格統計儀表板(Activity Rings 等)
- 📧 每週日 22:00 自動寄出 Email 週報

## 隱私
- 純前端產生,你填的店家資料**不會上傳任何伺服器**
- 點擊統計用共用 Cloudflare Worker,但每家店有獨立 namespace,資料完全隔離
